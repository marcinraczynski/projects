# Podglądy projektów

Publiczne podglądy stron dla klientów, publikowane przez GitHub Pages z gałęzi `main` (folder główny).

Zasady:
- każdy projekt w osobnym folderze, np. `solid-hale/`, `kplus-hero/`; foldery nie zależą od siebie, więc projekty ze sobą nie kolidują;
- adres podglądu: `https://marcinraczynski.github.io/projects/<folder>/`;
- nowy projekt dopisz do listy w `index.html`;
- każda strona ma `noindex, nofollow`, żeby nie trafiała do wyszukiwarek.
